```

┌─────────────────────────────────────────────────────────────┐
│ ┌────────────┬────────────┬────────────┬────────────┐     │
│ │   Tab 1    │   Tab 2    │   Tab 3    │   Tab 4    │     │

│ └────────────┴────────────┴────────────┴────────────┘     │
└─────────────────────────────────────────────────────────────┘

Tab Specifications:
- variant: "fullWidth" (equal width distribution)
- Text Transform: none (normal case)
- Font Size: 14px
- Font Weight: 500 (selected), 400 (unselected)
- Indicator Color: #0c4da2 (Standard Bank Blue)
- Indicator Height: 2px
```
